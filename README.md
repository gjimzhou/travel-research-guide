# Travel Research Guide

Public research notes on luxury-hotel selection, itinerary design, destination logistics, and travel-planning frameworks.

The repository intentionally excludes personal itineraries, booking details, home/work information, relationship events, and individual travel preferences. Destination-specific notes are written as reusable research conclusions.
